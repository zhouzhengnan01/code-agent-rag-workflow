# Page topology — `/web-agents`

1. **Fixed primary header** — brand and desktop links, GitHub indicator, login/start CTAs, responsive menu.
2. **Hero** — uppercase eyebrow, 68px desktop title, short lead, orange pill CTA, original illustrated hero image.
3. **Measured benchmark** — large two-line heading and supporting paragraph; 1200×640 SVG benchmark visualization, benchmark metadata/link.
4. **Four feature rows** — each is a 50/50 desktop grid (one column at compact widths), separated by rules:
   - Thousands of agents in parallel → 24-column cell matrix.
   - Runs on our own stealth browsers → 81% vs 2% horizontal bars.
   - Real-time web monitoring → event-height tick bars.
   - Structured outputs → JSON sample and caption.
5. **API / code showcase** — copy, explanation, quickstart link; two-column desktop composition with code tabs and snippet panel.
6. **Closing CTA** — one large line and orange “Run your first agent” action.
7. **FAQ** — six disclosure items, first expanded by default.
8. **Footer** — six groups, system/status and product-map copy; grid on desktop, accordion rows on compact layout.
9. **Cookie notice** — fixed lower overlay on first visit; local accept/reject choice.

The page uses one scrolling document; the only fixed visual layer is the 64px header and first-visit cookie notice. Content max width is 1200px and is centered. The source page's scroll-triggered visual reveals belong to the four feature figures; navigation, tabs, FAQ, and footer disclosures are click/keyboard interactions.
