FAQ

A web agent is an LLM that drives a real browser: it reads the page, decides what to click or type, and works through a task the way a person would. That is the difference from a scraper, which follows selectors someone wrote by hand and breaks the moment the page changes.

You choose per run. The default is GPT-5.6 Luna. A first top-up unlocks every supported model. Compare the current choices and token rates on the pricing page.

Browser agents are evaluated on real browser tasks. The benchmark above compares successful task completion across models on the same set of 106 tasks.

Agents run in isolated stealth browser sessions with proxy infrastructure designed to reach sites that block a stock headless browser.

Cost depends on the model and the work a task takes. Runs are metered, so you can match the model and budget to your use case.

Results are returned as structured data. You can retrieve them through the API or receive webhook callbacks when a run finishes.
